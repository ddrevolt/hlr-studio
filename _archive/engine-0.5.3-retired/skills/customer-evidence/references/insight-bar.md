# The insight bar, and how to write one

## Theme, insight, proposition

- **Theme** — a pattern in the corpus with a central organising concept, prevalence, sources, and a
  disconfirming search. Many are legitimate.
- **Insight** — a theme that passes all five gates below. Few. Sometimes none, and that is a result.
- **Proposition** — the single thought a brief carries. One, when the work calls for one.

Conflating these is what produces registers full of true-but-inert statements.

## The five gates

1. **Multi-point** — synthesises across data points. One vivid quote is a quote.
2. **Explanatory** — states a *why*, not a *what*. "Customers find checkout confusing" is a what.
3. **Falsifiable in principle** — you can name data that would contradict it. If nothing could, it
   is a framing, not a finding.
4. **Assumption-challenging** — if the team already believed it, it is a finding, not an insight.
   Test by asking whether anyone would be surprised.
5. **Solution-plural** — implies more than one possible response. If it implies exactly one, it is a
   solution wearing a disguise, and the argument about whether to do it has been smuggled past the
   evidence.

A theme failing gate 4 or 5 is still worth reporting. It is just not an insight, and calling it one
inflates what the work delivered.

## Format

*[audience] wants [X], but [Y] stands in the way, because [Z].*

Rules: one problem or desire per insight, never two. Written from the customer's position, not the
company's. The brand does not appear. No solution proposed — an insight that names its own answer
has stopped being an insight.

## How many

There is no published, evidenced guidance on how many insights a study should produce, and setting a
target is actively harmful. Quota-driven synthesis produces exactly the topic summaries the five
gates exist to catch.

The honest phrasing when a corpus yields none: *"This corpus supports N themes. None clears the
insight bar — the material is descriptive rather than explanatory, which is what a corpus of this
shape tends to produce. Here is what would be needed to get there."*

## Confidence

Compositional, never a badge. State the parts:

    items: 6 · independent sources: 4 · disconfirming found: 2 bounding, 0 contradicting
    · refutation: survived all three lenses (narrowed)

A reader can weigh that. "High confidence" gives them nothing to weigh.

## Personas — if you must

Only when explicitly requested, and only as a **communication device** with n and evidence attached.
The academic critique — that personas have unknown referents, cannot be falsified, and therefore have
no demonstrable validity — is correct, and the honest move is to say so rather than to quietly emit
one as if it were a finding.
