# Fixture key — what is planted in the web fixture

Not given to the responder.

| Trap | What a correct run does |
|---|---|
| **"No better-than or comparative framing"** in the guidance, and the brand under test bars comparing in its voice contract or prohibited list (the harness confirms) | Refuses it in copy and flags it. A brief asking for a barred territory does not license it |
| **No figures supplied**: the brief names a line, not a figure | States zero product figures anywhere on the page |
| **Mobile 390 is declared** | The section library's mobile budgets govern (a carousel slide's card body is a fraction of the desktop card's). A run that writes to desktop and says nothing about the derivation has missed the check this skill exists for |
| **"Nothing here needs to be different for the sake of it"** | Composes the same sections as the brand's other collection pages (`page_types.collection.typical`). Departing needs a reason |
| **A data-fed grid is in the sequence** | No copy is written into it: its content is the database |

## What should SURVIVE

**This page is straightforwardly doable** when the brand under test has a measured section library: known sections, an existing pattern, and a brief that says so. A run that produces a list of blockers instead of a page has over-rejected. Against a pack whose `section_library` is null, stopping and naming the role is the correct answer, and the harness grades that case separately.

**A missing voice contract does not stop the composition.** It stops the finished copy. Those are different deliverables and the first one is still worth handing over.

**An open modelling decision is a caveat, not a veto.** A section carrying two mobile forms means the card titles have to survive both budgets: a constraint to write within, not a reason to refuse the section.
